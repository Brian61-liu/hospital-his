{{ _('常见问题') }}

{{ _('挂号时提示“未找到该就诊卡号”怎么办？') }}

{{ _('说明患者尚未建档。点击挂号页右上角“新患者建档”，保存后系统会自动带着新卡号回到挂号页面，无需重新输入。') }}

{{ _('挂错号了可以退吗？') }}

{{ _('可以。在“门诊挂号 → 今日挂号列表”中找到该记录，点击“退号”，挂号费原路退回。已开始就诊的号不能退。') }}

{{ _('号源是如何计算的？') }}

{{ _('每位医生每个时段（上午 / 下午）提供 {0} 个号源，选择医生后系统会实时显示剩余号源；号源已满时无法提交。', quota) }}

{{ _('开处方时为什么会出现红色过敏警告？') }}

{{ _('系统会将药品的过敏原与患者档案中的过敏史进行比对（如青霉素过敏的患者开阿莫西林）。如确需使用，需勾选“已评估过敏风险”后才能提交，以防用药差错。') }}

{{ _('医保如何结算？') }}

{{ _('收费时选择“医保结算”，城镇职工医保统筹支付 {0}%，城乡居民医保统筹支付 {1}%，自费患者不能选择医保结算。', (ratio['城镇职工医保'] * 100)|int, (ratio['城乡居民医保'] * 100)|int) }}

{{ _('出院费用怎么计算？') }}

{{ _('住院费用 = 住院天数 ×（床位费 + 护理费 ¥{0}）。不足 1 天按 1 天计算。出院时与预交押金自动结算，多退少补。入院押金不少于 ¥{1}。', nursing_fee, min_deposit) }}

{{ _('医生如何让患者住院？') }}

{{ _('医生在接诊页点击“开住院证”，填写入院诊断后提交。病区护士会在“住院管理 → 待入院申请”中看到申请，安排床位、收取押金后完成入院。医生可在工作台查看申请进度，患者放弃住院时可撤销申请。') }}

{{ _('病区和床位在哪里设置？') }}

{{ _('护士长可在“住院管理 → 病区设置”中新增或撤销病区、批量增加床位、调整床位费，并将床位设为“维修”或“停用”（这些床位不会出现在入院可选床位中）。在院患者需要换床时可办理“转床”，系统会保留转床记录。') }}

{{ _('为什么有的床位不能删除？') }}

{{ _('有在住患者或历史住院记录的床位不能删除，以保证病历可追溯；不再使用时请将其设为“停用”。') }}

{{ _('患者缴费后不想取药了，怎么退费？') }}

{{ _('到“收费结算 → 已缴费未取药”中找到该处方，点击“办理退费”，费用按原支付方式退回（医保部分退回医保账户）。药品已发出的，需要先到药房退药。') }}

{{ _('住院押金不够了怎么办？') }}

{{ _('住院床位卡片和护士工作台会用红色标出“欠费”的患者。护士可在床位卡片中点击“补交押金”收取，出院时多退少补。') }}

{{ _('患者去做检查，医生怎么接诊下一位？') }}

{{ _('在接诊页点击“患者暂离”，病历和处方草稿会保存，患者回到候诊队列；检查结果出来后再次接诊即可。有患者正在就诊时不能直接叫下一位，以免遗漏。') }}

{{ _('如何修改登录密码？') }}

{{ _('点击右上角自己的姓名进入“个人中心”修改密码。忘记密码请联系系统管理员在“人员管理”中重置为 123456。') }}

{{ _('药房发药提示库存不足？') }}

{{ _('请到“药房管理 → 药品库存”中为对应药品办理入库，再返回发药。低于预警线的药品会在工作台和库存列表中以橙色标出。') }}
