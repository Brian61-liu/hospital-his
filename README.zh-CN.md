# 医院信息管理系统（HIS）

[English](README.md) | **简体中文**

基于 **Flask + SQLite + HTML/CSS/JavaScript** 的医院信息管理系统，覆盖完整的门诊流程
（挂号 → 接诊 → 收费 → 发药）和住院流程（住院申请 → 安排床位 → 转床 → 出院结算），
为五类医院岗位提供各自的功能页面。

界面支持 **中文 / English 双语**，可在顶部栏或登录页切换；两种语言各有一套独立的演示数据。

![医生工作台](docs/screenshots/zh/dashboard.png)

## 功能

| 模块 | 说明 |
|---|---|
| 登录与权限 | 按岗位显示菜单，记住上次工号，账号停用，修改密码 |
| 工作台 | 不同岗位显示不同统计；医生只看到本科室数据 |
| 患者档案 | 建档、编辑、搜索，查看就诊记录、费用明细和住院记录 |
| 门诊挂号 | 支持 7 天内预约，实时号源，打印挂号凭条，退号 |
| 医生工作站 | 叫号、电子病历、处方 **过敏与库存校验**、暂存草稿、开具住院证、打印病历 |
| 收费结算 | 医保结算（统筹 70% / 50%），未取药处方退费，当日收费流水 |
| 药房管理 | 发药自动扣减库存，入库，调价，库存预警 |
| 住院管理 | 待入院申请、床位一览、押金、转床、出院结算（转床后床位费分段计算）、病区与床位设置 |
| 人员管理 | 新增员工、停用 / 启用账号、重置密码（仅管理员） |
| 帮助中心 | 业务流程图、岗位权限、快捷键、常见问题 |
| 多语言 | 中英文界面，每种语言一套演示数据 |

### 业务流程

- **门诊：** 建档 → 挂号 → 医生接诊开方 → 缴费 → 取药
- **住院：** 医生开具住院证 → 护士安排床位并收取押金 →（转床）→ 出院结算

## 快速开始

环境要求：Python 3.8+

```bash
git clone https://github.com/Brian61-liu/hospital-his.git
cd hospital-his
pip install -r requirements.txt
python app.py
```

浏览器打开 <http://127.0.0.1:5000/>。

- 首次运行会自动创建 `hospital.db`（中文）和 `hospital_en.db`（英文）并写入演示数据。
- 重置演示数据：`python database.py`。
- 部署时请通过环境变量 `SECRET_KEY` 设置随机密钥。

## 项目结构

```
hospital-his/
├── app.py              # Flask 路由、权限控制与页面逻辑
├── database.py         # 表结构、中英文演示数据与业务函数
├── i18n.py             # 界面语言选择与翻译函数
├── translations_en.py  # 英文对照表（以中文原文为键）
├── requirements.txt
├── static/
│   ├── css/style.css   # 统一样式
│   └── js/main.js      # 时钟、快捷键、确认弹窗、消息提示
├── templates/          # Jinja2 模板，均继承 base.html
└── docs/screenshots/   # README 截图（en / zh）
```

### 多语言实现

- 界面文字以中文书写，Python 与模板中用 `_()` 包裹，JavaScript 中用 `t()` 包裹。
- `translations_en.py` 给出每条中文的英文对照；带编号的占位符（`{0}`、`{1}`）让英文可以按自己的语序排列。
- “待诊”“已缴费”等状态值在数据库中保存为中文，只在显示时翻译，两种语言共用同一套业务逻辑。
- 界面语言优先取切换按钮写入的 `lang` Cookie，没有时按浏览器的 `Accept-Language` 判断。

## 设计原则

| 原则 | 系统中的体现 |
|---|---|
| 系统状态可见 | 待办角标、就诊进度条、实时号源与金额 |
| 贴近真实场景 | 页面按医院真实岗位划分；医生开住院证、护士安排床位 |
| 用户可控 | 退号、退费、撤销住院申请、操作确认弹窗 |
| 一致性 | 各页面统一布局、配色、按钮和状态标签 |
| 防错 | 过敏提醒、重复挂号检查、号源与库存校验 |
| 识别而非回忆 | 记住工号、最近患者、历史就诊、处方草稿 |
| 灵活高效 | 快捷键（`/`、`Alt+数字`）、一键叫号、常用选项 |
| 简洁美观 | 医院蓝主题、卡片式布局、只显示本岗位内容 |
| 错误恢复 | 表单就地提示错误并保留输入，友好的错误页 |
| 帮助文档 | 帮助中心提供流程图和常见问题，字段旁有提示 |
